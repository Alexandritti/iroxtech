# IROX — Industrial Robotics Integration

Адаптивный лендинг на Next.js 15 / React 19.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Что менять

- `app/page.js` — контент и структура
- `app/globals.css` — дизайн и адаптив
- `app/layout.js` — SEO metadata

## Перед публикацией

Форма сейчас демонстрационная: submit не отправляет данные. Подключите Formspree, Telegram Bot, CRM или собственный API route. Почта на сайте: `hello@iroxtech.ru`. Добавьте юридические реквизиты и политику обработки данных.
